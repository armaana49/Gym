# Gym app

1. Create a new public repo on GitHub (e.g. `gym`).
2. Upload all the files in this folder to the repo's main branch.
3. Repo → Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)` → Save.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/gym/`.
5. On iPhone, open that link in **Safari** → Share → **Add to Home Screen**.

Ticks are saved on your phone. Open the app from the home-screen icon each time so they stay in one place.
